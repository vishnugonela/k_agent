# Development roadmap

1. Phase 1 – Kubernetes intelligence
   Foundation
   - Cluster discovery
   - Pod and workload tracking
   - CPU, memory and disk metrics
   - Events and logs
   - Natural-language CLI
   - Kubernetes API documentation retrieval
2. Phase 2 – Agentic troubleshooting
   - CrashLoopBackOff diagnosis
   - ImagePullBackOff diagnosis
   - Pending pod analysis
   - Root-cause investigation
   - Manifest generation and correction
   - Validation and approval workflows
3. Phase 3 – IDE integration
   - MCP server
   - VS Code extension
   - /kagent commands
   - Workspace analysis
   - YAML editing
   - Git diff and PR generation
4. Phase 4 – DevOps automation
   - Helm chart generation
   - Dockerfile generation
   - Image build and scanning
   - GitHub Actions integration
   - Jenkins integration
   - Deployment and rollback
5. Phase 5 – Plugin ecosystem
   - Plugin discovery and registration
   - Third-party MCP servers
   - Prometheus and Grafana
   - Argo CD and GitOps
   - Container engine integrations
6. Phase 6 – Enterprise platform
   - Web dashboard
   - Multi-cluster management
   - RBAC and OIDC
   - Audit trails
   - Agent performance monitoring
   - Policy-based autonomous remediation
